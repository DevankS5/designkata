# DesignKata

LLD practice with feedback you can check.

Pick a low-level design problem, write your design as short notes plus a class diagram, submit it, and get feedback that quotes your own design back to you. Then take the twist: a new requirement, the way an interviewer would add one, and see how much of your design had to change.

Work in progress. Built for the CipherSchools engineering assignment (September 2026).

## Run it

Requires Node 24 (see `.nvmrc`).

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
